# It's Almost Night

Прототип одиночной FPS-защиты крепости. Игрок собирает ресурсы, строит Ядро и
укрепления, затем переживает ночные волны.

Текущий milestone: **One Night**.

## Требования

- CMake 3.25+
- Ninja
- компилятор с C++20

raylib 6.0 ищется в системе. Если библиотека отсутствует, CMake загружает
закреплённый тег `6.0`.

## Стандартные операции

```bash
# configure
cmake --preset debug

# build
cmake --build --preset debug

# test
ctest --preset debug

# run
./build/debug/its_almost_night
```

Sanitizers на поддерживаемых Unix-платформах:

```bash
cmake --preset sanitizers
cmake --build --preset sanitizers
ctest --preset sanitizers
```

## Управление

- `Enter` — начать забег
- `WASD` — движение
- `мышь` — обзор
- `Shift` — бег
- `Space` — прыжок
- `ЛКМ` — удар киркой
- `Q` — переключить кирку/ружьё
- `V` — улучшить ружьё
- `ЛКМ` с ружьём — выстрел
- `G` — бросить бомбу
- `1` — выбрать Ядро
- `2` — выбрать стену
- `3` — выбрать стрелковую башню
- `4` — выбрать золотую шахту
- `5` — выбрать пушку
- `6` — выбрать замедляющую ловушку
- `7` — выбрать ворота
- `E` — открыть/закрыть ворота под прицелом
- `F` — полностью отремонтировать постройку под прицелом
- `X` — продать постройку под прицелом за 50% стоимости
- `U` — улучшить постройку под прицелом; без цели — Ядро
- `ЛКМ` в режиме строительства — установить
- `ПКМ` — отменить строительство
- `колесо мыши` — повернуть постройку
- `N` — начать закат досрочно
- `O` — включить неограниченные ресурсы
- `K` — отладочно уничтожить всех врагов текущей волны
- `I` — включить/выключить бессмертие игрока
- `M` — отладочно нанести 50 урона Ядру
- `Z` — выбрать тип врага для отладочного создания
- `B` — создать выбранного врага во время волны
- `T` — включить/выключить замедление времени
- `C` — показать/скрыть коллайдеры
- `H` — показать/скрыть flow field
- `L` — показать/скрыть занятые spatial-hash ячейки
- `J` — скрыть/показать HUD
- `F2` — показать/скрыть графическую debug-панель
- `F1` — показать/скрыть shadow map
- `F3` — включить/выключить тени
- `F4` — включить/выключить туман
- `F5` — включить/выключить off-screen pipeline
- `F6` — включить/выключить частицы
- `F7` — включить/выключить blob shadows
- `Shift+F7` — переключить силу AO: 0/20/30/35%
- `F8` — включить/выключить bloom
- `F9` — включить/выключить SSAO
- `F10` — переключить качество графики
- `F11` — переключить render scale: 1.0/0.75/0.5
- `F12` — включить/выключить единый world shader
- `Shift+F12` — включить/выключить процедурное небо
- `Y` — заморозить/разморозить визуальное время
- `[` / `]` — вручную сдвинуть визуальное время
- `'` — мгновенно переключить Dawn/Day/Dusk/Night
- `\` — вернуть автоматическое визуальное время
- `P` — пауза
- `R` — перезапуск сцены
- `Esc` — выход
