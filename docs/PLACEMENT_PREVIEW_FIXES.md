# Превью опор и обод миникарты

Рассчитанная геометрия опоры больше не исчезает только из-за ошибки цены,
дальности или радиуса ядра. `PlatformFramePlacement::hasGeometry()` отдельно
проверяет готовность координат: высота призрака 1×1 берётся с той же
платформы, что и при допустимом размещении. Проверки разрешения строительства
и списания ресурсов сохраняются. Нерассчитанные опоры не рисуются в начале
координат.

Для этажа без нижней опоры используется составной предпросмотр этажа и
фундамента. Существующая подходящая платформа используется повторно через
`PlatformFramePlacement::existingFrame`: она не рисуется второй раз,
не анимируется как новая и повторно не оплачивается. Недостающая опора
включается в цену; установка обоих объектов и откат при ошибке происходят
вместе. Существующая платформа при откате не удаляется. Опоры по-прежнему
подчиняются ограничениям высоты, радиуса, коллизий и доступных ресурсов.

По последнему уточнению пользователя поведение рампы оставлено прежним.
Убран только запасной красный цилиндр-кружок при отсутствии превью.
Новые правила красного призрака рампы и повторного использования её опор
не включены в результат.

Обод миникарты — неподвижная окружность из 192 сегментов, без синусоидальных
неровностей и выступов. Карта, компасные обозначения и предупреждения
продолжают ориентироваться по направлению взгляда.

Проверки: Release-сборка, `ian_presentation_events_smoke` с повторным
использованием опоры этажа, `ian_ui_viewport_smoke`. Дополнительно проверены
реальное списание цены только этажа на готовой опоре и отсутствие частично
созданных объектов при недостаточном бюджете. `RendererMathTests` содержит
проверку сохранения платформы при ошибках радиуса/цены/дальности.
