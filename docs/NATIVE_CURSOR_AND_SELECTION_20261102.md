# Курсор меню и обводка при высоком качестве

Картинка руки в меню теперь используется как системный GLFW-курсор, поэтому её движение обслуживает ОС независимо от кадров игры. Сохранены рисунок, точка нажатия и масштаб UI. При смене размера окна курсор пересоздаётся; при невозможности создать системный курсор используется прежняя отрисовка. Переходы в игровой захват мыши остаются через DisableCursor/EnableCursor, показ курсора не центрирует его каждый кадр. Из экранов меню и фидбека удалён принудительный HideCursor перед рисованием.

Для обводки убрано расхождение времени ветра между мировой геометрией и маской: обе используют время начала одного кадра. Сравнение с глубиной сцены учитывает полный пиксель сцены и её собственное разрешение, а не один случайный отсчёт. Самоперекрытие соседними гранями выбранной модели больше не должно вырезать треугольные разрывы при включении SSAO/высокого качества. Отдельная проверка маски и грунта сохранена.

Выполняются только итоговые Release-сборки Mac и Windows, без дополнительных тестовых прогонов. Воспроизведение артефакта на конкретном Windows GPU после правки не проверялось. Зависимости не добавлены: GLFW уже используется в настройках экрана. Формат сохранений не менялся.
