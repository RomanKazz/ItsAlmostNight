# Отклик мыши

Мышь считывалась каждый кадр, но камера показывала только углы последнего физического тика (60 Гц). Между тиками накопленный ввод оставался невидимым. Теперь к углам камеры добавляется ещё не потреблённый физикой ввод мыши: после физического тика угол переходит в snapshot без повторного применения. Сглаживание, предсказание скорости и изменение чувствительности не добавлены.

Наклон ограничен теми же 89°; при паузе, выборе улучшения, появлении/возрождении эффект отключён. Инерция модели оружия получает изменение угла на каждом кадре, согласованное с камерой, вместо толчков с частотой физики.

Выполнена одна итоговая Release-сборка Mac-приложения. Дополнительные тестовые прогоны не выполнялись по просьбе пользователя. Публичные интерфейсы и формат сохранений не менялись. Windows ZIP относится к предыдущей версии.
