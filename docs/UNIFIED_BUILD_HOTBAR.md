# Единый хотбар строительства

Все открытые сооружения, добывалки, стены, ворота и ловушки находятся в одном
ряду. После них с отступом идут платформа и рампа. Колесо проходит весь ряд;
C переключает только экипировку. До установки ядра доступен только слот ядра.
Прежний обход строительных категорий на C и деталей на V удалён.

У платформы один слот:

- земля — фундамент;
- середина существующей платформы — следующий этаж;
- край платформы — продолжение её этажа;
- верхний край рампы — примыкающая платформа.

Во время протягивания тип и высота фиксируются до отпускания ЛКМ. После
окончания размещения инструмент снова выбирает тип по поверхности. Проверки
опоры, занятости, ресурсов и расстояния сохраняются. В цене выбранного слота
используется фактический тип превью. Внутренние Foundation/FloorPlatform и их
ID сохранений остаются прежними.

Максимальный каталог Godmode содержит 21 слот. Длинный ряд уменьшается до
ширины окна и поднимается над индикаторами здоровья. Обычный короткий ряд
сохраняет прежний размер и положение. Первые 15 слотов сохраняют клавиши
1–0, -, =, [, ], ;. Остальные доступны колесом без выдуманных горячих клавиш.

Интерфейсы: `ConstructionHotbarItem::gapBefore`, единый
`makeConstructionHotbarLayout`, `MaximumBuildingHotbarSlots = 21`;
`HudViewState::activeModularBuildPiece` передаёт фактическую цену платформы.
`indexOf(FloorPlatform)` и `modularBuildHotbarIndex(FloorPlatform)` возвращают
общий слот платформы. Категории остаются метаданными старого каталога;
переключения категорий в App больше нет.

Проверки: BuildingSystemTests — состав, фильтрация, уникальность, общий слот,
ядро до старта; AppPresentationEventsSmoke — C без действия, проход колесом
между сооружениями/платформой/рампой, сброс отмены, контекст земли/этажей,
фиксация протягивания и фактическое размещение верхнего этажа;
UiViewportSmokeTests — полный ряд с выделенной платформой на семи размерах
окна, дополнительные снимки обычного ряда и ядра.

Сборки Debug и Release выполнены. Полный набор Debug проверен; найденный
сдвиг хотбара экипировки исправлен и соответствующий UI smoke повторно
пройден. В Release пройдены три проверки: presentation events, upgrade UI,
viewport UI. Снимки обычного ряда, ядра и полного каталога проверены визуально.
Полный прогон ASan/UBSan: 42/42, без ошибок памяти и UB. Проверки
`git diff --check` и `git diff --cached --check` пройдены.
