# Стабильный шум земли на разных GPU

Старый hash в `world.vs`, `world.fs` и `grass_instanced.fs`:

```glsl
fract(sin(dot(position, vec2(127.1, 311.7))) * 43758.5453)
```

Он усиливает различия округления dot/sin до заметно разных случайных значений.
Эти значения управляют крупными земляными проплешинами и смешиванием материалов,
поэтому похожая геометрия может иметь разные широкие коричневые области на разных GPU.
GLSL не гарантирует одинаковую точность тригонометрии между реализациями:
[Khronos, GLSL 4.60, precision](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.html).

Три функции заменены одинаковым 32-битным целочисленным перемешиванием координат
ячейки. Результат содержит 24 бита и точно переводится в float. Отрицательные координаты
обрабатываются через signed → unsigned conversion, арифметика unsigned работает по модулю
2^32. Не добавлены текстуры, проходы или настройки цвета. Сами формы шумовых областей
могут отличаться от старого sine-узора; материал и цветокоррекция не перенастраивались.

`ian_terrain_noise_smoke` извлекает функции из настоящих шейдеров и проверяет по
18 фиксированным значениям в vertex и fragment stages: 108 точных GPU readback-проверок.
Включены отрицательные и дробные координаты, начало координат и дальние ячейки.
Также линкуется полный world shader. Необязательный первый аргумент — папка шейдеров
другой сборки, например Windows assets, чтобы проверить патч без пересборки EXE.

В локальной Windows-папке на Desktop изменены только эти три функции; исходные
шейдеры сохранены с суффиксом `.before-ground-noise-fix`, EXE не менялся.
`dist/huawei-ground-hotfix-20261026/assets/shaders/` содержит совместимые файлы
именно из этой Windows-сборки, с сохранением остальных шейдерных интерфейсов.

Сведения о видеокарте Huawei и скриншот симптома не предоставлены. Зависимый от GPU
hash исправлен и проверен на доступном OpenGL, но причина конкретного изображения
на физическом Huawei пока не подтверждена повторным запуском на том ноутбуке.
