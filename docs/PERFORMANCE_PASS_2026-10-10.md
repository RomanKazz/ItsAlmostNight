Цель: повысить FPS на 30–40% и уменьшить длинные кадры без снижения качества изображения. Первый проход выполнен; целевой прирост пока не подтверждён.

Чтобы получить +30–40% к медианному FPS, нужен интервал около 3.13–2.91 ms. Основная дополнительная стоимость медленных кадров находится в present/ожидании GPU, а не в симуляции. В записи максимум 19 врагов: выводы о больших поздних волнах из этого лога делать нельзя.

Два отдельных события:

- Frame 1398: переход menu → build, input 95.18 ms, весь кадр 98.90 ms. Создание забега синхронное; полностью эта задержка ещё не устранена.
- Frame 1746: первая видимая миникарта, её обновление 40.90 ms, генерация/обновление target 39.06 ms, весь кадр 48.74 ms.

`frame_interval_ms` заканчивается в начале текущего кадра и содержит работу предыдущего кадра. Причину конкретного кадра нужно сопоставлять с `frame_ms`. GPU queries асинхронные; этапы могут включать отложенную работу драйвера. Их нельзя складывать в итоговый бюджет.

## Изменения

1. GPU profiling: максимум один elapsed query каждые восемь кадров, этапы чередуются. CPU timings продолжают записываться каждый кадр. Ранее несколько query заставляли дополнительно сбрасывать render batches каждый кадр. В текущем рабочем дереве один этап получает выборку примерно раз в 96 кадров; это не инструмент для поиска единичного GPU-spike по каждому subpass.
2. Terrain: отсекаются чанки вне реального frustum текущего прохода, включая shadow camera. Bounding boxes кешируются при сборке и учитывают опускание геометрии во время появления мира. Дальность, LOD и mountain backdrop сохранены.
3. Viewmodel: composite shader топора, кирки и дубинки рисуется только внутри консервативного прямоугольника текущей анимации. UV и Retina scaling сохранены. Посохи с частицами и бомба сохраняют полный проход. При пересечении near plane используется полный проход.
4. Миникарта в текущем рабочем дереве готовит статический landscape во время подготовки забега, до появления HUD. Это перенос стоимости в загрузку, а не устранение генерации. Отдельная первая задержка HUD должна исчезнуть; суммарное время старта может вырасти.
5. Добавлены CSV-счётчики: свежесть GPU viewmodel queries, число выданных queries, физический размер вывода, смена run state, время подготовки миникарты, число нарисованных/отсечённых terrain chunks. Анализатор обновлён для новых столбцов и пропускает GPU-метрики без счётчика свежести.

Публичные дополнения: `RendererPerformanceStats::{gpuQueriesIssued, terrainChunksSubmitted, terrainChunksCulled}`, соответствующие поля `PerformanceFrameRecord`; getters счётчиков TerrainRenderer; helper `viewModelCompositeBounds`; `camera_culling::Frustum`. Рабочая интеграция миникарты добавляет `GameUi::prepareMinimapLandscape` / `MinimapLandscape::prepare`.
