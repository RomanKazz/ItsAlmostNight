# Лазер

Оборона с непрерывными лучами и усилением урона при удержании цели.
Новая модель подключена с исходным ригом: неподвижная подошва, yaw-стойка,
корпус и голубые элементы следуют pitch. Точка запуска совпадает с MUZZLE_01.

## Начальные параметры

| Параметр | Уровень 1 |
|---|---:|
| Цена: дерево / камень / кристаллы | 45 / 35 / 25 |
| HP | 160 |
| Радиус | 10 м |
| Сектор | 90° |
| Интервал урона | 0.15 с |
| Базовый урон за импульс, в UI | 1.8 |
| DPS до разгона / на полном разгоне, без крита | 12 / 48 |
| Разгон | 3 секунды, ×1 → ×4 |
| Pitch | −12° … +20° |

`multiplier = 1 + 3 × clamp(focusSeconds / 3, 0, 1)`.
Focus растёт только при наведении на одну живую цель. Смена/потеря цели,
выход из радиуса, потеря наведения, продажа, очистка боя и reset сбрасывают его.
Отмеченная линзой новая цель не перехватывает уже удерживаемую цель.
Attack Speed ускоряет импульсы урона, скорость разгона от него не зависит.
Все попадания проходят общий hit flow: крит, отбрасывание, предметы, kill events.
Отдельных projectile, burst sequence и случайного промаха у луча нет.

## Совместимость

Работают Damage, Attack Speed, Range, Quantity, Bounces, Bounce Range,
Crit Chance, Crit Damage, Knockback. Pierce, Projectile Speed, Duration и Size
отключены.

Quantity создаёт независимые параллельные лучи по основной цели. Каждый наносит
полный урон и имеет собственную цепочку дополнительных целей по Bounces.
Рикошеты сохраняют полный разогнанный урон; одна цепочка не посещает цель дважды.
Например, Quantity=3 и Bounces=1 дают шесть попаданий за импульс, если цели живы.
Дробные значения сохраняются в статах; floor применяется только при использовании.

Восемь уровней характеристик используют общие карточки/магазин/debug и слоты
обороны; максимум ограничен ядром. Каждый уровень добавляет 0.45 UI урона за
импульс, 0.4 м дальности и 4% базовой частоты импульсов.
Восемь полных визуальных вариантов находятся в `assets/models/buildings/laser_levels/`.
`GraphicsResources::laserTowerModel(level)` загружает их при инициализации;
рендер, тени, обводка, превью и точный raycast выбирают текущий уровень.
Риг, исходная линза и MUZZLE сохранены. Контракт и сравнение:
`art/models/laser_levels/HANDOFF.md`, `art/models/laser_levels/levels_1-8.png`.
BuildingType=18, RunUpgradeEffect::UnlockLaserTower=63 — только новые append-only ID.
Сохранения используют расширяемые массивы и прежние ID.

## Presentation и производительность

Непрерывный луч, мягкий голубой ореол, белое ядро, движущиеся блики и звёздочка
в точке контакта. Толщина растёт вместе с разогревом. Один общий triangle batch,
ограничение 256 сохранённых сегментов и 96 видимых лучей, без allocation/particle
objects на импульс. Сначала отображается основной луч каждой башни, затем
дополнительные лучи и рикошеты. Визуальные ограничения не обрезают расчёт урона.
Звук — один тихий пространственный loop для всех лазеров с fade при прекращении
стрельбы/паузе; импульсы не запускают отдельные громкие звуки.

Молнии теслы и лазер закрывают мировую обводку объектов позади через уже
существующий ink-occluder MRT. Они проходят обычный depth test и не записывают
геометрию в opaque depth, поэтому объекты впереди корректно их закрывают.

## Проверки

`ian_laser_tests`: реальный рост урона, сброс при смерти цели/потере радиуса,
Attack Speed, crit, compatibility, восемь уровней, очистка/reset, карточки и save/load;
три луча с рикошетом, шесть реальных попаданий, дробные значения и независимые цепочки.
`LaserGraphicsChecks.hpp`: реальный ModelResource, mesh order, collider/socket,
соответствие дула CPU/renderer в разных позах, icon, raycast, beam visibility/depth.
`ian_presentation_events_smoke`: настоящий App VFX pass с постобработкой и
контуром объекта позади разряда; тест падает при удалении ink-occluder исправления.

Ручной игровой playtest не выполнялся. Начальные DPS, время ×4 разгона и цена
требуют проверки против танков/элит: это осознанная специализация на живучих целях.
