## Код второго прохода

Небо ранее рисовалось fullscreen до земли. Ночью это означает расчёт procedural stars/galaxy/aurora даже для пикселей, которые затем закрывает terrain.

- `assets/shaders/sky.vs` помещает fullscreen quad на far depth (clip z = w).
- `Renderer::drawSky` включает depth test и отключает depth writes только для неба. После прохода восстанавливает стандартное 2D-состояние.
- Gameplay сначала рисует terrain, затем небо. Закрытые пиксели отбрасываются depth test до дорогого fragment shader. Небо остаётся перед объектами с прозрачностью/частицами. Никакие octave, цвета, звёзды или детали сияния не убраны.
- `GraphicsResources` загружает новый sky vertex shader. Публичный интерфейс renderer не изменён.
- `PerformanceFrameRecord` получил `windowFocused`, `windowMinimized`, `windowFocusChanged`. CSV дополняется `window_focused`, `window_minimized`, `window_focus_changed`; старые столбцы сохраняют порядок. Последний флаг сравнивает фокус в начале кадра и после native event polling.
- Анализатор текущего рабочего дерева выводит показатели по фазам, статистику focused frames при наличии новых полей, основные этапы самых длинных кадров и корректное пояснение состава EndDrawing.

Focus-флаги помогают отличать смену окна. Они не обнаруживают каждый скриншот и не доказывают отсутствие фоновой нагрузки.
