# Источники опыта и индикация урона

В обычном забеге XP дают уничтоженные враги, деревья/камни/кристаллы, бочки, обычные и золотые крейты. Награды из этих источников по-прежнему выпадают физическими кристаллами опыта; бонус тома опыта сохраняется.

Убраны прямые начисления за постройки и модули, ремонт, завершение ночи, досрочный вызов волны, открытие отдельных сундуков и старый бонус Blueprint. Старые числовые параметры наград оставлены читаемыми для совместимости, но больше не включают эти источники. Отладочная выдача опыта остаётся инструментом разработчика, недоступным при стандартно выключенных отладочных клавишах.

Урон игроку включает красную виньетку по краям на 0.60 секунды, урон Ядру — фиолетовую на 0.85 секунды. Интенсивность учитывает силу попадания, повторные попадания продлевают сигнал. Центр прозрачен; сигналы независимо затухают, а указатель направления к повреждённому Ядру также фиолетовый. Настройка уменьшения вспышек ослабляет эффект. Отрисовка использует один шейдер и один полноэкранный проход только при активном сигнале.

Внутренние интерфейсы: удалены `Simulation::earlyWaveInsightBonus` и одноимённое поле snapshot; добавлены `GameUi::drawDamageVignette` и флаг `DamageIndicator::core`. Формат сохраняемого прогресса не изменён.

По просьбе пользователя после добавления индикации выполнена только итоговая Release-сборка приложения. Дополнительные тестовые сборки и прогоны не запускались; новый промежуточный тестовый стенд удалён. Ранее изменённые существующие тестовые файлы успешно скомпилированы.

Mac-приложение обновляется на месте, без замены `user_settings`. Имеющийся Windows ZIP относится к предыдущему релизу.
