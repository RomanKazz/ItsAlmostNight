# Мортира

Дальняя артиллерия против групп: медленный навесной снаряд, большой взрыв,
ближняя слепая зона. Использует существующие CannonSystem, ProjectilePool,
FinalAttackStats и общий hit flow; отдельной системы урона нет.

| Уровень 1 | Значение |
|---|---:|
| Дерево / камень / кристаллы | 50 / 40 / 20 |
| HP | 180 |
| Дальность / слепая зона | 18 / 4 м |
| Обстрел | 360° |
| Урон, UI | 60 |
| Интервал | 4 с |
| Радиус взрыва | 3.25 м |
| Базовый горизонтальный темп траектории | 6 м/с |
| Время жизни | 8 с |
| Возвышение | 35–75° |

Уровни характеристик 1–8: +10 UI урона, +0.5 м дальности, +0.12 м радиуса
за уровень; интервал `4 / (1 + 0.06 * (level - 1))`.
Карточки улучшают все копии, максимум ограничен ядром. Восемь визуальных уровней: золотые пояса, опоры, защитные щёки, охлаждение
ствола, стойка с боеприпасами и усиленный открытый раструб.

Физическая траектория решается от актуального дула до текущей позиции цели:
`time = max(1.7, distance / 6) * 6 / projectileSpeed`, затем ограничивается
углами 35–75°. Вертикальная скорость `(height + gravity*time*time/2)/time`.
Projectile Speed сокращает время полёта до механического предела в 35°.
Нет телепортации в цель или самонаведения: движущийся враг может уйти из взрыва.

Quantity создаёт дополнительные снаряды с разнесёнными точками падения.
Bounces запускает следующий навесной прыжок к ещё не поражённому врагу;
проверяется реальное расстояние от столкновения, включая высоту. Pierce,
Crit, Damage, Attack Speed, Size, Duration, Knockback, Range и Bounce Range
используют общий физический hit flow. Дроби Quantity/Bounces/Pierce сохраняются,
floor применяется при использовании. Пушка и катапульта сохраняют прежние профили.

Три render mesh: base=0, pitch=1, yaw=2. Pivot Y=0.870 м; нейтральные 45° уже
заданы геометрией. Runtime pitch — только отклонение −10…+30°. MUZZLE_01
совпадает с CPU launch point. Подключены тени, обводка, raycast, размещение,
предпросмотр, сектор дальности/слепая зона, иконка, minimap, карточки/shop/debug,
save/load, общие мультяшные взрывы и ограниченный звуковой микс пушки.

Модели: исходная `mortar.glb` плюс `mortar_upgrades.glb`. L1 использует исходник,
L2–L8 рисуют только три дополнительные группы выбранного уровня; максимум шесть
mesh draws на здание. Группы двигаются с прежними настоящими шарнирами.
Renderer::drawMortar использует уровень во всех проходах, raycast учитывает декор.
Исходник и превью: `art/models/mortar_levels/`; авторинг/проверка:
`tools/create_mortar_upgrades.py`, `tools/validate_mortar_upgrades.py`.
7847 поз: полный yaw при 35/45/75° и pitch по 1°; пересечений новых подвижных
деталей с неподвижной базой/стойкой нет. Исходная PNG встроена байт в байт.

Круговой обстрел относится к поиску, удержанию и предпочтению отмеченных целей;
радиус/слепая зона сохраняются. Preview, hover overlay и строка сектора используют
тот же типовой helper defenseAttackArcDegrees(type, level).

Append-only IDs: BuildingType::Mortar=19, RunUpgradeEffect::UnlockMortar=64.
GraphicsResources::mortarModel и Renderer::drawMortar — новые точки рендера.

Проверки: `ian_mortar_tests` — траектория на разных высотах, Projectile Speed,
радиус/слепая зона/обстрел всех четырёх квадрантов, групповое поражение, crit, дроби, реальный рикошет,
pooling/reset, прогрессия и save/load. `MortarGraphicsChecks.hpp` — загрузка GLB,
три mesh, socket, соответствие CPU/render в девяти позах, иконка, raycast,
рендер всех восьми уровней и при 35/75°, различие геометрии уровней, raycast по
задней защитной рамке L8.

Ручной gameplay playtest не выполнялся. Проверить цену, 60 урона и 3.25 м
радиуса против плотных волн: большая площадь компенсируется временем полёта,
слепой зоной и медленной стрельбой.
