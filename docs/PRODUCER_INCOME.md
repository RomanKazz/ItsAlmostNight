# Доход в карточках добывающих зданий

Карточки лесопилки, каменоломни и кристальной шахты показывают одну строку
`Доход: X → Y/мин`, без отдельных размера пачки и времени цикла. При первом
получении здания показывается `0 → базовый доход`, затем текущий и следующий.

Производительность уровня N = базовая производительность × `(1 + 0.20 × (N − 1))`.
При стандартных бонусах лесопилка даёт 20, 24, 28, 32 дерева в минуту;
каменоломня — 10, 12, 14, 16 камня; шахта — 4, 4.8, 5.6, 6.4 кристалла.
Общие бонусы, бонусы конкретного здания и штраф за повреждение продолжают
применяться к настоящему доходу.

Ресурсы выдаются целыми пачками. Увеличение пачки на некоторых уровнях
компенсируется интервалом, поэтому оно не создаёт скачка среднего дохода.
Интервал больше не округляется до четверти секунды. Сохраняется защитный
минимальный интервал 0.25 секунды при экстремальных множителях.

Публичные интерфейсы не менялись. Проверка `runCrystalMineSystemTests`
проверяет базовую выдачу, апгрейд, сохранение прогресса, бонусы, повреждение
и одинаковый прирост дохода на всех 255 уровнях всех трёх производителей.
