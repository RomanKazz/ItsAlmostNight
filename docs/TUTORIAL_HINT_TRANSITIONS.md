# Переходы подсказок обучения

Под миникартой текущий шаг показывается с пустым квадратом. После реального
выполнения в квадрате рисуется зелёная галочка, плашка коротко подсвечивается
и остаётся на экране 0.52 секунды. Затем она уходит вверх с затуханием за
0.18 секунды, следующая появляется справа за 0.20 секунды. CIKO сохраняет прежнее оформление, счётчик дерева не возвращается.
Подсказки действий показывают только квадрат и текст: `CHOP A TREE`,
`PLACE CORE`, `PLACE DEFENSE`, `SURVIVE NIGHT`. Клавиша остаётся только
у инструкции входа в режим строительства (`TAB` или назначенная игроком).

Выполнение проверяется отдельно от смены подсказки: достаточно дерева,
открыт режим строительства, построено ядро, построена оборона. Смена режима
снаряжения сама по себе не выдаёт галочку за строительство. Если инструкция
исчезла по иной причине, она просто затухает. Последняя выполненная задача
также показывает галочку перед исчезновением.

Состояние сбрасывается для нового забега и остаётся только для первой игры.
Пауза и окно выбора улучшений останавливают анимацию. Все переходы выполняются
в обновлении представления, без изменения игрового прогресса и таймеров.

Публичные данные: `TutorialHintVisual` передаёт отступы, прозрачность, прогресс
галочки и подсветку; необязательный `HudViewState::tutorialHint` передаёт
подготовленное представление в HUD. Для автономных превью HUD сохраняется
показ текущей подсказки из снимка симуляции с пустым квадратом.

Проверки: Release-сборка, `ian_presentation_events_smoke` (реальное выполнение,
удержание галочки, переход к следующему шагу, отсутствие ложной галочки при
смене инструкции, пауза, исчезновение последнего шага),
`ian_run_upgrade_ui_smoke` с визуальной проверкой трёх состояний плашки.
