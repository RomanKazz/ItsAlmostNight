# Constant movement speed — 2026-10-11

Ground sprint has been removed. Base movement speed is now 6.0 m/s instead of
5.0 m/s (+20%). Holding Shift does not change ground speed. Dash keeps its
existing timing and speed. Acceleration, braking, diagonal normalization,
air control, water penalties, class bonuses and movement upgrades still apply.

## Settings and compatibility

The former Sprint settings row now reads `FLY DOWN (SANDBOX)` with a Russian
translation. Shift remains the default binding for descending during sandbox
flight. The saved action ID and JSON key `sprint` are unchanged, preserving
existing custom bindings.

No public structure or enum layout changes. `PlayerCommand::sprint` remains
for sandbox flight descent. `GameplayBalanceDefinition::sprintSpeed` remains
as an optional legacy configuration field, ignored by movement; omitted values
fall back to `walkSpeed`. Existing configs containing it still load.
