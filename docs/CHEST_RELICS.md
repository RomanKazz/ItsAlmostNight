# Предметы из сундуков — новый набор

18 новых предметов: Common 5, Rare 5, Epic 3, Legendary 5 (включая Зеркало).
Глобальные открытия, стартовый пул и покупки за серебро описаны в
[META_PROGRESSION.md](META_PROGRESSION.md). Случайный лут включает только
стартовые и купленные предметы; редкость и формулы эффектов не меняются.
Старые ID 0–25 сохранены для старых сохранений и классовых стартовых предметов,
но исключены из нового выпадения и каталога. Новый набор занимает ID 26–43.
Редкость предмета фиксирована; она не умножает силу его эффекта ещё раз.
Томы, пулы характеристик карточек, стоимость и правила карточек не изменены.

| Предмет | Редкость | Правило для n стаков |
| --- | --- | --- |
| Жёлудь | Common | При ручной рубке шанс `1 − 0.9^n` на рост того же дерева через 1.5 сек. Если место занято игроком или постройкой, рост ждёт освобождения. Обычное мировое возрождение ресурсов не меняется. |
| Лоток старателя | Common | При каждом ручном добывающем попадании по камню шанс `1 − 0.95^n` на 1 кристалл. |
| Ремонтный гвоздь | Common | При ручном ремонте шанс `1 − 0.9^n` обойтись без ресурсов. Кулдаун успешного ремонта сохраняется. |
| Ботинок лесоруба | Common | Полностью срубленное вручную дерево даёт множитель скорости `1 + 0.1n` на 5 сек.; повторная рубка обновляет длительность. |
| Счёты | Common | С момента получения учитываются полностью добытые ресурсы отдельно по типу. `1 + 0.01n × min(100, count)` к соответствующим добывалкам. Дополнительный стак не обнуляет прогресс. |
| Боевой жетон | Rare | Реальная смена оружия вооружает бонус: `+25%n` следующему успешному попаданию игрока по врагу. Повторный выбор того же оружия не вооружает его. |
| Боевая пружина | Rare | После 3 сек. простоя башня заряжает следующее попадание: `+40%n`. Стрельба с промахами также прерывает простой. Одновременные снаряды, Pierce и цепь не получают бонус каждый. |
| Ремонтный магнит | Rare | Ручной ремонт лечит ближайшую другую повреждённую постройку в 6 м на `30%n` фактически восстановленных HP, с ограничением её максимумом HP. Вторичное лечение не запускает цепной ремонт. |
| Сирена | Rare | При HP строго ниже 40% скорость атак башни умножается на `1 + 0.15n`. Работает через реальные интервалы TowerSystem и CannonSystem. |
| Клевер | Rare | Открытие бочки даёт `10%n` вместимости каждого из трёх ресурсов; ящики не считаются бочками. |
| Горный молоток | Epic | Ручное разрушение камня наносит другим камням в 4 м `50%n` урона завершающего добывающего удара. Не создаёт рекурсивную цепь. Добытые ресурсы выдаются обычным путём, Счёты учитывают разрушение. |
| Рассветная монета | Epic | На рассвете добавляет `floor(stock × 0.05n)` каждого ресурса, до остальных наград за волну. Вместимость хранилища сохраняется. |
| Последний огонёк | Epic | Разрушенная стреляющая башня становится неуязвимым призраком на `8 + 5(n−1)` сек. Использует ту же TowerSystem/CannonSystem, снаряды, прицеливание и модификаторы. Призрак не блокирует движение, не ремонтируется и не производит ресурсы. |
| Предохранитель Ядра | Legendary | Раз за ночь оставляет Ядру 1 HP при смертельном ударе, останавливает врагов и их снаряды на `5 + 2(n−1)` сек. Боссы тоже останавливаются. Во время остановки повторный урон Ядру блокируется. |
| Кристальный сейф | Legendary | На начало ночи фиксируется `min(3, floor(crystals/25))` вкладов. Без списания. Множитель урона башен на ночь `1 + 0.1n × deposits`. Последующая трата кристаллов не снимает бонус. |
| Чертёж восстановления | Legendary | На рассвете восстанавливает до n разрушенных стреляющих башен с 40% HP. Занятое место, ресурс или уничтоженная опора запрещают восстановление; запись остаётся до следующего рассвета. Продажа и ручное удаление не считаются разрушением. |
| Удачливый кубик | Legendary | +n независимых проверок вероятностных ручных эффектов: Жёлудь, Лоток и Гвоздь. Итоговый шанс `1 − (1−p)^(itemStacks × (1+dieStacks))`; одно действие запускает каждый эффект не более одного раза. Не меняет редкость лута или карточек. |
| Зеркало улучшений | Legendary | Каждая `max(2, 6−n)` выбранная карточка характеристик применяется дважды с той же редкостью и тем же seed. Получение нового оружия/здания и служебные карточки не считаются. Улучшения существующих башен и шрайны считаются; двухстатовая карточка — один выбор. |

Шанс дополнительного предмета из контейнера не меняется. Распределение редкостей
сундуков: исследовательские 60/27/10/3%, наградные 72/20/6.5/1.5%
(Common/Rare/Epic/Legendary). Все предметы своего тира равновероятны.

Прогресс Счётов, Зеркала, RNG, ночных эффектов, разрушенных башен и призраков
сохраняется в `relics`. Сохранения без этого поля получают пустое состояние.
Вход в новый забег сбрасывает всё. Ночной checkpoint сохраняет обычную семантику
повтора ночи; предметы не обходят её.

## Модели

- Актуальный второй проход: `tools/refine_chest_relic_models.py`, выполнен через Blender MCP с отдельным просмотром и правками каждого предмета. `tools/create_chest_relic_models.py` — исторический первый вариант.
- Runtime: `assets/models/items/relics/*.glb`, по одному mesh/material, встроенный atlas.
- Редактируемая сцена: `art/models/chest_relics/refined/chest_relics.blend`; рядом отдельный `.blend` каждого предмета.
- Иконки: `assets/ui/relics/*.png`, 256×256, отрендерены из настоящих моделей.
- Общий лист: `art/models/chest_relics/refined/contact_sheet.png`.
- Сравнение первого и второго проходов при одинаковом свете: `art/models/chest_relics/refined/before_after.png`.
- Front/side/back/top и перспектива каждого предмета: `art/models/chest_relics/refined/views/`.
- Соседние игровые модели под тем же светом: `art/models/chest_relics/refined/references/`.
- Отчёты экспорта и чистого повторного импорта: `manifest.json`, `validation.json` рядом со сценой.

Образцы стиля — существующие nail, blueprint и powerup magnet. Авторский размер
всех новых моделей по максимальной оси 1.3, центр в начале координат; существующий
масштаб рендера предметов даёт видимый размер около 0.47 м. Нормали/UV/PNG,
повторный импорт и загрузка через игровой ModelResource проверяются отдельно.
Подробная сдача второго прохода, проверки и пути: `art/models/chest_relics/refined/README.md`.

## Проверки

`ian_relic_tests`: выпадение всех 18 предметов и тиеров, формулы и Кубик,
локальное возрождение, добыча, бафф Ботинка, прогресс Счётов, ремонт и Магнит,
Сирена в башнях и артиллерии, Жетон, простой Пружины, Клевер, рассветный доход,
Предохранитель и Сейф, настоящая стрельба призрака, восстановление и Зеркало,
сохранение и сброс состояния. `ian_presentation_events_smoke` также проверяет
JSON roundtrip. `ian_graphics_smoke` проверяет загрузку и рисование всех моделей;
`ian_unlock_menu_smoke` проверяет иконки и навигацию нового каталога.
