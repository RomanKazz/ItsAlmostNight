## Изменения третьего прохода

Единственное изменение runtime — `assets/shaders/postprocess.fs`; публичные интерфейсы и настройки не изменены.

- При нейтральных color curves не рассчитываются веса shadows/midtones/highlights и `exp2`, результат которых был единицей.
- При gamma=1 сохраняется clamp отрицательных каналов, пропускается тождественный `pow`.
- При выключенном dithering не вычисляется Bayer matrix.
- Для пикселя без outline edge не рассчитываются атмосферные `pow`/`exp` и итоговое смешивание с нулевым ink.
- Для обычного object-пикселя сосед того же или меньшего depth не может создать front-surface ink: проверка возвращает ноль до view-space reconstruction и дополнительных slope samples. Исключение material class 4 для effect fragments сохранено.

Размер, fading и цвет обводки не меняются. Активные настройки curves/gamma/dither продолжают использовать прежний путь. Никакая детализация неба, растительности, геометрии или эффектов не убрана.

## Проверка пикселей и скорости

До изменения сохранена точная копия рабочего shader. Один и тот же Release raylib исполняет старый и новый fragment shader на render target 1920×1080. Источник содержит RGB gradients, background/terrain/objects/vegetation/effect material tags, неодинаковую глубину и AO. Четыре режима:

1. Нейтральные curves, gamma=1, dithering off.
2. Изменённые curves и gamma=1.6.
3. Palette, dithering, bloom, low-health и vignette.
4. Отрицательный brightness и gamma=0.8.

Во всех четырёх случаях **0 изменённых пикселей, max channel delta=0**. Effect tag ограничен значением 255, чтобы class 4 корректно присутствовал в 8-bit texture. Это синтетическая проверка на стандартной perspective projection, не доказательство для любой возможной камеры или сцены.

Изолированный postprocess benchmark: `glFinish` после прохода, по четыре раунда с чередованием порядка before/after, 20 warmup и 200 измерений на вариант. Медиана round p50: before 0.574 ms, after 0.533 ms — время меньше на 7.0%, throughput выше примерно на 7.6%. Измеренный набор содержит смесь material tags; это не весь кадр и не дополнительный общий прирост 7.6%.

Дополнительно одинаковая Release-сцена: terrain seed 42, 80 деревьев, кирка, HUD, night=1, MSAA 4×, profiling off. Только shader различается; старая версия загружается из отдельного asset-каталога.
