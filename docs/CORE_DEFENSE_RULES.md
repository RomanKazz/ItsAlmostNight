# Ядро, уровни обороны и ремонт

- В обычном забеге общий уровень боевого типа ограничен уровнем ядра, максимум 8. До установки ядра предел равен 1: новый тип можно получить, стартовый улучшить нельзя.
- Карточки достигшего предела типа исключаются из наград уровня и генерации магазина. Покупка старого/заблокированного предложения повторно проверяет доступность и не списывает монеты. После повышения ядра тип возвращается в пул.
- Старые сохранения и ранее усиленные здания не понижаются. Если общий уровень уже выше ядра, дальнейшие обычные карточки недоступны до открытия следующего уровня. Debug-выдача сохраняет обход ограничения ядра.
- Ручной ремонт ядра запрещён, включая ремонт полностью здорового ядра ради ручного укрепления. Команда отклоняется с `BuildingActionError::Unsupported`, ресурсы не расходуются.
- «Ремонт всех» полностью удалён: нет кнопки, отложенного действия и команды симуляции. Остальные здания и модульные конструкции ремонтируются индивидуально.
- По уточнению пользователя удалён только ремонт: прирост здоровья от повышения максимального HP и лечение способностями персонажей сохранены.

## Интерфейсы и совместимость

- `runDefenseLevelLimit(coreLevel)` централизует предел карточек; `Simulation::runUpgradeAvailable` и обычное применение карточки используют его одинаково.
- Удалены `RepairAllBuildingsCommand`, `PlayerCommand::repairAllBuildings`, `SimulationSnapshot::repairAllCoinCost`.
- Стабильный ID `GameEventType::AllBuildingsRepaired` оставлен зарезервированным, событие больше не создаётся. Старые параметры стоимости ремонта всех в конфигурации читаются для совместимости, игровой функции не дают.
- `BuildingSystem::validateRepair` запрещает ядро. Общие функции изменения максимального здоровья и лечения способностями сохраняют прежнюю семантику.

## Цвет дерева при ударе

Раньше дерево выбирало биом по смещённому ударом корню модели. На границе даже смещение в несколько сантиметров меняло палитру всей кроны.

`WorldMaterialState::plantBiomeAnchor` фиксирует исходное положение корня: XY содержат мировые X/Z, Z включает привязку. Одноимённый uniform используется только для индивидуальной отрисовки; обычные экземпляры продолжают выбирать палитру по своей матрице. Пока остаточное смещение от удара не исчезло, дерево рисуется индивидуально даже после окончания вспышки. Кеш материала учитывает привязку и сбрасывает её для следующего объекта.

## Проверки

- `CoreDefenseGateChecks.hpp`: предел до ядра/на уровнях 4–5, обновление старых предложений, блокировка покупки без оплаты, повторное открытие карточки, запрет ремонта ядра и сохранение индивидуального ремонта/прироста HP.
- `DefenseCardProgressionChecks.hpp`: общие уровни, существующие/новые экземпляры, магазин, сохранения и сброс с учётом ядра.
- `checkVisualBiomeRendering`: ищет фактическую границу биомов, сдвигает дерево через неё и сравнивает GPU-кадры. С привязкой цвет сохраняется; без привязки меняется. Следующий объект проверяет отсутствие утечки uniform.
