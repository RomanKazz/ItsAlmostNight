# Том опыта

`RunUpgradeEffect::ExperienceGain` добавлен в конец каталога под ID 71. Обычная карточка даёт +10% получаемого опыта; остальные редкости — +12%, +14%, +16% и +20%. Бонусы копий складываются. Том использует стандартный слот и предел пяти уровней обычных числовых томов. Доступен среди наград уровня, в магазине между волнами и в персональных шрайнах.

Бонус применяется в центральном `Simulation::grantConfiguredInsight` ко всем источникам опыта после diminishing returns. Новый `InsightGrantContext::rewardMultiplier` не расходует бюджет категории быстрее. Дробный опыт хранится как `double`: десять наград по одному опыту при одной обычной копии дают 11 опыта. Уже полученный опыт не пересчитывается.

Множитель вычисляется из сохранённых сил тома и персональных благословений, отдельное накопленное состояние не требуется. Загрузка не начисляет бонус повторно. Старые массивы сохранений дополняются нулём существующим `readExpandableFixedArray`; прежние ID не меняются.

Карточка и панель статистики показывают бонус опыта в процентах. Иконка — отдельная SVG-книга со звездой, растеризуется существующим загрузчиком UI. Новые зависимости не добавлялись.

Проверки покрывают получение карточки, дробный опыт, складывание редкостей и шрайна, повторную загрузку, сброс забега, неизменность бюджета diminishing returns и совпадение предпросмотра с симуляцией.

Debug собран; полный `ctest --preset debug` пройден: 45/45 без пропусков. Иконка отдельно проверена рендером lunasvg: 256×256, прозрачные углы. `git diff --check` пройден.
