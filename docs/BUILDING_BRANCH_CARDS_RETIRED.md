# Отдельные карточки развилок зданий

Из обычной прокачки убраны шесть карточек: Trap Pulse, Turret Shrapnel,
Cluster Payload, Heavy Shell, Scattershot и Cluster Shell. Карточки открытия
и повышения уровня зданий, общие тома атаки и улучшения шрайнов остаются.
Эволюции этим изменением не реализуются.

`legacyBuildingBranchUpgrade` перечисляет зарезервированные эффекты.
`retiredRunUpgrade` исключает их из выдачи за уровень, магазина, энциклопедии
и видимого каталога Godmode. Старое задание `upgrade_cluster` удалено из
JSON и резервного каталога. Обычные шрайны уже используют только общие статы
и этих карточек не содержат.

При загрузке незавершённый выбор со старой карточкой заменяется актуальным,
а старые предложения магазина очищаются, включая закреплённые. Купленные
ранее эффекты и их сохранённые ID остаются совместимыми. Пустой слот магазина
заполняется при следующем обновлении предложений по обычным правилам.
Низкоуровневые боевые модификаторы и служебные debug-выдачи оставлены для
старых сохранений и тестовых сценариев; карточки в UI недоступны.

Проверки: загрузка каждого из шести эффектов, замена ожидающих наград,
очистка закреплённых предложений без удаления активных карточек, повторная
выдача после реролла, скрытие в каталоге Godmode, сохранение обычных карточек
зданий и томов, отсутствие невыполнимого задания в резервном каталоге.
Публичные форматы сохранений и индексы эффектов не меняются.

Валидация: Debug собран; в полном прогоне пройдены 41 набора, после обновления
ожидаемого числа заданий и карточек повторно пройден общий набор `ian_tests`.
Release собран: `ian_tests` и четыре проверки UI (магазин, каталог, задания,
меню забега) пройдены. `git diff --check` и проверка staged diff пройдены.
