# ADR-001: nlohmann/json для игровых конфигураций

## Статус

Принято.

## Решение

Использовать header-only `nlohmann/json`, совместимый с `3.11.3`. CMake сначала
ищет системный пакет версии не ниже `3.11.3`, затем загружает закреплённый тег
`v3.11.3`.

## Причины

- зависимость разрешена техническим планом;
- строгий и понятный API валидации;
- нет собственного неполного JSON-парсера;
- библиотека не попадает в слой отображения или raylib.

Загрузка выполняется до создания симуляции. При ошибке используются
скомпилированные fallback-значения, а результат содержит список ошибок.
Сейчас через JSON настраиваются противники, волны, здания, ружьё, бомба и
экономика.
