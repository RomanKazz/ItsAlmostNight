# Footer icons

User-provided SVG Repo files:

- `settings.svg`: `gear-setting-settings-svgrepo-com.svg`
- `exit.svg`: `exit-svgrepo-com.svg`

Original paths and square view boxes are preserved. The nominal size is
128×128 and fills are white so the menu can tint them cream or gold.
GameUi rasterizes them once at initialization; the footer draws them at a
uniform scale with a black outline. SVG Repo attribution comments are kept.
