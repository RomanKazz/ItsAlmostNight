# Assets

Runtime-ресурсы проекта. Пути считаются относительно корня запуска игры.

- `audio/` — звуки и относящиеся к ним лицензии.
- `data/` — баланс, локализация и игровые определения в JSON.
- `maps/` — определения карт.
- `models/` — модели, анимации и их локальные текстуры.
- `shaders/` — GLSL-шейдеры рендера.
- `textures/` — общие текстуры мира.
- `ui/` — шрифт, панели и иконки интерфейса.

Импортные наборы моделей хранятся вместе со своими `.bin`, текстурами и
лицензиями. Не переносите отдельный `.gltf` без его соседних зависимостей.
