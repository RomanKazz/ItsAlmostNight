# Пушка: золотые улучшения L1–L8

Подключено к существующим уровням пушки. L1 — простая исходная модель;
L2–L8 — новая пара полных накладок выбранного уровня, не накопление всех мешей.

| Уровень | Видимые изменения |
| --- | --- |
| 1 | Простой деревянный лафет, тёмный ствол |
| 2 | Широкий золотой пояс основания и усиление казённика |
| 3 | Крупные золотые щёки с оранжевой бронёй |
| 4 | Золотой дульный обод, тёмные ступицы с золотыми гайками |
| 5 | Оранжевый кожух казённика, второй пояс, четыре крепления подошвы |
| 6 | Более массивное дульное кольцо, красная муфта, боковые силовые планки |
| 7 | Красная броня лафета, три золотые отметки, продольные рёбра казённика |
| 8 | Самый широкий дульный обод, усиленный задний пояс и крупные плечевые накладки |

## Файлы и редактирование

- Runtime: `assets/models/buildings/cannon.glb`.
- Исходник: `art/models/cannon_levels/cannon_levels.blend`.
- Генератор геометрии/GLB/границ: `tools/generate_cannon_upgrades.py`.
- Студия и исходник: `tools/render_cannon_levels.py`.
- Проверка: `tools/validate_cannon_levels.py`.
- `comparison.png`: слева направо огнемёт, пушка L8, L4, L1; общий свет и масштаб.
- `level_1.png`…`level_8.png`, front/side/back/top, крайние наклоны −15°/+55°.

В Blender коллекции `CANNON_MODEL`, `CANNON_COLLISION`, `CANNON_STUDIO`.
По умолчанию показан L8. Накладки имеют свойства `level`, `motion` и именованные
группы вершин по материалу (`gold_trim`, `orange_armor`, `red_armor`, `dark_metal`).
Для другого уровня включить его пару и скрыть предыдущую. Studio не экспортировать.
Оригинальные имена рига сохранены для совместимости с существующим ассетом.

## Палитра и контракт

Оригинальная Kenney PNG встроена в GLB и упакована в Blender. Золотой диапазон
Blender UV: U=.65625, V=.285–.465 — тот же, что у ядра и огнемёта.
Оранжевый/красный/тёмный металл также используют исходную colormap.
Здесь нет новых текстур, запечённых теней или статичных VFX.

После удаления коллайдера: 16 render meshes. Индексы 0/1 — исходный наклоняемый
ствол/поворотный лафет, затем по две накладки уровней 2–8: yaw/pitch.
У улучшенной пушки два дополнительных draw calls, как до замены. Максимум
1896 треугольников накладок на одновременно показанный уровень; точные counts и
границы каждой пары в `manifest.json`. Footprint остаётся 2×2 м.

Ось наклона исправлена на реальную высоту центра ствола:
GLB (0, .7001184225082397, 0), вращение X. Раньше pivot находился на .149311 м
и при поднятии ствола казённик проходил через основание. Нейтральная геометрия,
позиция дула, коллайдер и исходные vertex buffers сохранены. Локальный offset
ствола компенсирует перенос pivot; `CannonRig.hpp` использует ту же координату.
Дуло GLB: (0, .7002042531967163, −.5782914683222771), вперёд −Z, вверх +Y.
Прицеливание, bounds и raycast используют исправленную ось и новые границы.

Все детали лафета получают общий yaw; накладки ствола дополнительно получают pitch.
Поэтому взаимные зазоры не зависят от yaw. Наклон проверяется с шагом 1° во всём
рабочем диапазоне −15°…55°. Новые детали не пересекают друг друга, движущийся
ствол не пересекает новые накладки лафета или сплошную подошву. Контакты исходных
опор со стволом/его облегающей бронёй отражены отдельно в `validation.json`.

## Проверки и лицензия

Чистый импорт GLB, встроенная PNG, UV, unit normals, замкнутые компоненты,
положительный объём, зазоры при движении, повторяемость генератора.
Runtime graphics smoke проверяет загрузку, визуальное различие всех уровней,
наклон, raycast дульного кольца и восстановление материалов после tint.
Автоматические игровые рендеры проверены; ручной бой в игре не проверялся.
