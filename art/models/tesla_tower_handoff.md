# Tesla tower — модель по концепту

Новая базовая тесла для ItsAlmostNight: ступенчатое оранжевое основание,
четыре стальные опоры с восьмигранными болтами, три ребра катушки,
толстое оранжевое верхнее кольцо и голубой гранёный шар.
Пропорции подогнаны под семейство Kenney; высота 1.44 м, подошва 1.2 м,
диаметр шара 0.36 м. Один полный базовый вариант, без уровней улучшения.

## Файлы

- Runtime: `assets/models/buildings/tesla_tower.glb`.
- Редактируемый исходник: `art/models/tesla_tower.blend`.
- Превью: `art/models/tesla_tower_preview.png`.
- Сравнение: `art/models/tesla_tower_comparison.png`.
- Виды front/side/back/top: `art/models/tesla_tower_views/`.
- Контракт: `art/models/tesla_tower_manifest.json`.
- Отчёт загрузчика: `art/models/tesla_tower_views/loader_report.json`.
- Генератор: `tools/create_tesla_tower_model.py`.
- Проверки: `tools/validate_tesla_tower_model.py`, `tools/validate_tesla_tower_loader.cpp`.

Сравнение снято при общем нейтральном свете с актуальным огнемётом и исходной
Kenney-пушкой, увеличенной до runtime-подошвы 1.2 м. Прежние `tesla` и `tesla_coil`
сохранены. Игровые ассеты других орудий не перезаписаны.

## Геометрия и палитра

Два видимых меша/primitives, два материала, одна встроенная PNG 512×512.
1412 видимых треугольников: корпус — 1188, шар — 224.
С коллайдером: три меша/primitives, три материала и 1424 треугольника.
`base_mesh` содержит 17 именованных vertex groups для отдельных деталей.
Круглые детали имеют 12 сторон, болты — 8; шар — 16 сегментов / 8 колец.
Боковины сглажены, торцы и грани шара сохраняют жёсткие нормали.

Использована неизменённая исходная `assets/models/buildings/Textures/colormap.png`:
PNG встроена в GLB и упакована в `.blend`. Оранжевые детали, дерево, металл
и голубой шар берут цвет из соответствующих участков одной палитры.
Материалы metallic = 0, roughness = 1. Шар имеет standard glTF emissive texture
с factor 0.65. Base Color остаётся голубым без emission.
Игровые молнии, bloom и свечение нужно подключить отдельно; статичные VFX
не включены в геометрию.

## Иерархия и координаты

Единицы — метры. Blender: +Z вверх / +Y вперёд;
GLB: +Y вверх / −Z вперёд / +X вправо.
Нейтральный `asset_root` стоит на полу (0, 0, 0), rotation = 0, scale = 1.
Коллекции `TESLA_TOWER_MODEL`, `TESLA_TOWER_COLLISION`, `TESLA_TOWER_STUDIO`.
Studio не экспортируется.

Модель неподвижна: yaw/pitch/recoil pivots, Armature и анимационные клипы
не нужны. Направление разряда определяется выбранной целью в игровом коде.
После удаления коллайдера render mesh 0 — `base_mesh`, 1 — `energy_mesh`.

Все Empty — прямые дети root. Координаты ниже даны в GLB, относительно root;
local и world относительно root совпадают. Scale = 1, rotation identity.

| Имя | X / Y / Z | Назначение |
| --- | --- | --- |
| `MUZZLE_01` | (0, 1.260, −0.200) | Передняя поверхность шара + 0.02 м; −Z вперёд / +Y вверх |
| `socket_effect_energy` | (0, 1.260, 0) | Центр шара для привязки разрядов/свечения |
| `socket_base` | (0, 0, 0) | Центр установки |
| `socket_ui_top` | (0, 1.540, 0) | UI, на 0.1 м выше модели |

Текущий загрузчик читает `MUZZLE_*`. Остальные Empty — контракт для интеграции;
их имена сами по себе не подключают эффекты. Для круговой атаки центр шара
и направление до цели позволяют рассчитывать точку выхода разряда на его поверхности.

## Коллизия и footprint

Видимые bounds GLB: X/Z [−0.6, +0.6], Y [0, 1.44].
`COL_BOX_BODY` — настоящий root-level box mesh с такими же bounds,
8 уникальных вершин, 12 треугольников; без `_WALK`. В Blender wireframe,
скрыт на превью, в GLB экспортирован. Загрузчик удаляет его из render model.

Рекомендуемый footprint — 2×2 клетки, локальные X/Z от −1 до +1.
Площадь стройки и блокировка перемещения назначаются в коде отдельно;
GLB-коллайдер не меняет их автоматически.

## Проверки и статус

Проверены сырой GLB, чистый повторный импорт, editable source, root/parents/TRS,
пол и bounds, UV, конечные единичные нормали и outward winding,
отсутствие вырожденных/дублированных граней, manifold после временной сварки швов,
C4/зеркальная симметрия и исходные байты PNG. Поворотные проверки неприменимы:
модель статична, механических движущихся частей нет.

Проверены текущие `GlbCollisionAsset` и `ModelResource` отдельной C++ пробой:
valid, один правильный box, один `MUZZLE_01` с правильными координатами/осями,
два видимых меша после удаления box и загруженная встроенная текстура.

Игровой код не изменён. Атака, молнии и эффекты новой модели ещё не подключены;
реальный playtest не выполнен. Подробный машинный отчёт — в manifest.

Геометрия создана для проекта по концепту пользователя. Палитра — Kenney
Tower Defense Kit 2.1, CC0; лицензия `art/references/kenney_tower_defense/LICENSE.txt`.

## Повторная сборка

Генератор запускать в отдельном свежем Blender-процессе. Он перезаписывает
собственные GLB/BLEND/превью; ручные изменения предварительно сохранить отдельно.

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --background \
  --python-exit-code 1 --python tools/create_tesla_tower_model.py
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --background \
  --python-exit-code 1 --python tools/validate_tesla_tower_model.py
```

После validator запускать loader probe: validator заново пишет manifest.
После ручных изменений экспортировать текущую сцену, не пересобирать генератором
поверх правок. Экспортировать MODEL и COLLISION, сохраняя скрытый box в GLB.
